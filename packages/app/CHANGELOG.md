# 2.5.2

_2026-09-14_

## English

### Changes

- This machine → Relay service: the "set / not set" pill next to the public address is gone — a visible address already means it is set, and the pill actually described the access password. When no access password is set, a separate "Access password" line now says so under the address.
- Relay operations: on narrow screens (including the installed PWA on a phone) the connected-nodes list is shown as record cards instead of a wide table.

### Fixes

- Relay operations page no longer lets the settings page scroll sideways into empty space on narrow screens; wide tables scroll inside their own box only.

---

## 中文

### 变更

- 多节点互联 → 本机 → 中继服务：公网地址旁不再显示「已设置 / 未设置」徽标——地址显示出来即代表已设置，该徽标实际说的是接入密码。未设置接入密码时，地址下方单独一行「接入密码」提示。
- 中继运营：窄屏（含手机上安装的 PWA）下接入节点改为记录卡展示，不再是宽表。

### 修复

- 中继运营页在窄屏下不再把设置页撑宽、向右滚进空白区域；宽表只在自己的盒子里横向滚动。
