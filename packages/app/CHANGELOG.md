# 2.18.0

_2026-11-17_

## English

### Features

- **Quick Login in the sidebar**: the bottom of the left sidebar now has a Quick Login button that opens the one-time login command dialog for all nodes from any page, the same as Settings → Nodes → Login Command.
- **Cleaner node table**: when a node's ports are unreachable, a small warning icon now appears after its name instead of two lines of text. Hover, focus or tap it to see which ports to allow in the firewall or security group.

### Fixes

- If the login command dialog fails to load, a message now asks you to try again instead of doing nothing.

---

## 中文

### 新功能

- **侧栏一键登录**：左侧栏最下方新增「一键登录」按钮，在任意页面都能打开全部节点的一次性登录命令，效果与「设置 → 节点 → 登录命令」相同。
- **节点表更简洁**：节点端口不可达时，改为在机器名后显示一个小警告图标，不再占两行文字；悬停、聚焦或点按图标可查看需要在防火墙或安全组放行的端口。

### 修复

- 登录命令对话框加载失败时会提示重试，不再毫无反应。
