# 2.0.2

_2026-09-07_

## English

### Changed

- **Settings → General → About** now reads like a regular About page: logo, product name, tagline and version, one sentence describing how this machine is installed and running (install method, service manager, run mode), and the copyright, license and project links. The previous list of label/value rows is gone.

### Fixes

- **Japanese interface.** Choosing 日本語 under Settings → General → Language is now saved; previously the choice silently fell back to English.

---

## 中文

### 变更

- **设置 → 通用 → 关于** 改为常见软件的关于页样式：logo、产品名、一句定位与版本号，一句话说明本机的安装方式、服务托管与运行模式，以及版权、许可证与项目地址链接；不再是一行一格的信息列表。

### 修复

- **日文界面。** 在「设置 → 通用 → 语言」选择日本語现在会保存；此前会静默落回英文。
