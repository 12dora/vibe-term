# 1.1.40

_2026-09-06_

## English

### Fixes

- **Sharing.** Settings → Sharing → Active now lists shares from every connected node, with a Node column; stopping, viewing or changing the password and copying links act on the node that owns the share. Previously only the current node's shares were shown, so a share of a remote terminal looked missing. History and share settings remain per node.

---

## 中文

### 修复

- **分享。** 「设置 → 分享 → 进行中」现在列出所有已连接节点上的分享并显示「节点」列；终止、查看 / 修改密码、复制链接都作用于分享所属节点。此前只显示当前节点的分享，远端终端的分享看起来像是消失了。历史与分享设置仍按节点显示。
