# 1.1.38

_2026-09-06_

## English

### Changes

- **File Transfer.** The send buttons now name the destination node ("Send to mesh-node-b"). A node with no configured file root opens at `/` so transfers work out of the box; once a file root is configured, browsing is limited to configured roots as before.

---

## 中文

### 变更

- **文件传输。** 发送按钮显示目标节点名（如「发送到 mesh-node-b」）。未配置文件目录的节点默认从 `/` 浏览，开箱即可传输；配置文件目录后仍只能浏览已配置的目录。
